# My Web Blog

A simple, responsive web blog built with HTML, CSS, and JavaScript.

## Features

- Clean, modern design
- Responsive layout that works on mobile, tablet, and desktop
- Multiple blog posts with dedicated pages
- Easy navigation
- Semantic HTML structure

## Getting Started

### Viewing the Blog

Simply open `index.html` in your web browser to view the blog homepage.

### File Structure

```
.
├── index.html      # Homepage with blog post previews
├── post1.html      # Blog post: Getting Started with Web Development
├── post2.html      # Blog post: Understanding Responsive Design
├── post3.html      # Blog post: Best Practices for Clean Code
├── styles.css      # Stylesheet for all pages
└── README.md       # This file
```

### Adding New Posts

To add a new blog post:

1. Create a new HTML file (e.g., `post4.html`) using the existing post files as templates
2. Update the `index.html` file to add a preview of your new post
3. Update the sidebar's "Recent Posts" section in `index.html`

## Browser Compatibility

This blog works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
